🗂️ ১️⃣ PHP Connection & Logic
php
Copy code
<?php
ob_start(); 
👉 ob_start():
এটি Output Buffering শুরু করে।
এর মানে হলো: পিএইচপি যখন আউটপুট তৈরি করে, তখন তা সরাসরি ব্রাউজারে যাবে না, বরং মেমরিতে জমা হবে ➜ পরে একসাথে পাঠানো যাবে।
কেন দরকার? ➜ কারণ আমরা header() দিয়ে redirect করতে চাই — আর এটি কাজ করে যদি আগে কোনো আউটপুট না যায়।

php
Copy code
$conn = new mysqli("localhost", "root", "2997", "db_driven_webapp");
👉 new mysqli():
আমরা MySQL Database এর সাথে কানেক্ট হচ্ছি।

localhost: সার্ভার অ্যাড্রেস (লোকাল)

root: ইউজারনেম

"2997": পাসওয়ার্ড (তোমার পাসওয়ার্ড)

db_driven_webapp: ডাটাবেসের নাম
